# Магнесия — сайт МРТ-центра (Якутск)

PHP 8.3 + Apache (OpenServer). База данных — SQLite, создаётся сама при первом обращении.

## Установка
1. Распакуйте папку `magnesia` в `OSPanel\domains\` (получится домен `magnesia`), либо в корень любого домена.
2. OpenServer → Настройки → Модули: выберите PHP 8.3 и HTTP Apache. Убедитесь, что включены `pdo_sqlite` и `sqlite3`.
3. Перезапустите OpenServer и откройте http://magnesia/
4. Папка `data/` должна быть доступна для записи (обычно так и есть).

## Вход в кабинет: /admin/login.php
| Роль | Логин | Временный пароль |
|---|---|---|
| Администратор | admin | Admin#2026 |
| Оператор | operator | Operator#2026 |
| Врачи | dyagileva, atlasov, glebov, timofeev, pevzner | Doctor#2026 |

При первом входе система потребует сменить пароль.

## Права
- **Администратор**: все заявки, направление заявки врачу, удаление заявок, добавление/удаление сотрудников, сброс паролей.
- **Оператор**: видит все заявки, меняет статус (новая / подтверждена / отменена), пишет заметки.
- **Врач**: видит только заявки, направленные ему; отмечает «подтверждена» / «выполнена», пишет заметки.

## Фото врачей
Положите файлы в `assets/img/doctors/` с именами: `dyagileva.jpg`, `atlasov.jpg`, `glebov.jpg`, `timofeev.jpg`, `pevzner.jpg`
(форматы jpg, png, webp). Пока фото нет, показываются инициалы. Рекомендуемый размер 640×720, до 150 КБ.

## Что поменять перед публикацией
- `includes/config.php` — телефон, адрес, соцсети, координаты карты (проверьте точку в Яндекс.Картах).
- `includes/helpers.php` — цены (`price_list`) и описания врачей (`doctors_info`).
- `privacy.php` — текст политики лучше показать юристу.
- Для боевого сайта включите HTTPS.
